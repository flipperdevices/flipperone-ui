# ProtoPie GUI Demo

![flipper_one_protopie_demo](https://github.com/user-attachments/assets/cb25be10-fee6-4d3d-b187-3dae5f14dbb2)

You can run the interactive Flipper One interface demo on the [ProtoPie](https://www.protopie.io/) platform.  
We use the ProtoPie demo as our main UI concept verification tool.

It works best via the mobile app, but it can also run in a browser without installing the app.

### How to run the ProtoPie demo

1. Install ProtoPie Player for [Android](https://play.google.com/store/apps/details?id=io.protopie.companion&hl=en&pli=1) or [iOS](https://apps.apple.com/us/app/protopie-player/id1015837511).

2. Open the following link on your mobile device:  
   https://cloud.protopie.io/p/8b3ce95e854c87471d14d3a0  
   **OR** scan the QR code using the ProtoPie mobile app:

### ProtoPie settings tips

* If ProtoPie Player freezes, double-tap with two fingers to open the menu and reload the prototype.

* In the settings, you can disable touch highlights and purple hint overlays to prevent them from interfering with the UI preview.
